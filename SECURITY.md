# Security policy

## Supported version

Security and privacy fixes are applied to the latest release.

## Reporting a vulnerability

Please use
[GitHub private vulnerability reporting](https://github.com/senlindesign/coding-wrapped/security/advisories/new).
Do not open a public issue for a bug that could expose local transcripts,
credentials, paths, or other private data.

Useful reports include the affected version, operating system, reproduction
steps, and a minimal synthetic fixture. Do not attach real session history.
