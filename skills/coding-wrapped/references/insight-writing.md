# Insight writing

## Editorial mix

- 70% fun facts and recognizable behavior;
- 20% human-agent relationship or memorable working pattern;
- 10% light, sourced advice.

The desired reaction is “原来我是这样和 AI 一起做东西的,” not “I received a
performance review.”

## Selection order

Prefer findings that are unusual, personal, story-like, and easy to visualize.
Useful categories include:

1. when the user codes;
2. how the user talks to the agent;
3. how the agent expands or branches the work;
4. repeated moments such as `continue`;
5. the user's resulting collaboration style.

Do not select four cards that tell the same story.

## Insight anatomy

Each insight contains:

- a short profile title;
- one factual headline;
- one sentence tying the number to the selected period;
- `you_did`, `agent_did`, and `your_style`;
- one light suggestion;
- evidence metric IDs and values;
- allow-listed source IDs;
- one illustration description and accessible alt text.

Write only in the locale requested by the generation brief. Keep UI labels and
copy in the same locale.

## Advice requirements

- Ground every suggestion in the insight's evidence.
- Reference at least one allow-listed source ID.
- Paraphrase the registered supporting claim.
- Do not attach a famous name unless the source actually supports the claim.
- Keep the suggestion to one action. Do not turn the card into a tutorial.

## Four-card diversity

- Use all four themes once: warm, blue, pink, green.
- Use four different composition names.
- At most one composition may use a center hub or network.
- Vary spatial stories: procession, cutaway machine, diagonal journey, room,
  archive, timeline, shelf, workshop, map, or stage.
